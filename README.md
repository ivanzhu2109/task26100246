# commission-calendar

订阅佣金日历库：从完整、只读的订阅快照出发，按自然月计算每个伙伴的应计佣金。
纯内存、纯 Python 标准库实现，无外部依赖，供上层财务模块直接调用。

## 安装与导入

将 `commission_calendar/` 包放入项目（或加入 `PYTHONPATH`）后：

```python
from datetime import date
from commission_calendar import CommissionCalendar, PriceRecord, Subscription
```

## 输入：订阅快照

```python
sub = Subscription(
    txn_id="TXN0001",            # 唯一 ASCII 交易编号
    partner_id="PARTNER_A",      # 伙伴标识
    deal_date=date(2024, 1, 31), # 成交日 = 服务起始日
    window_months=12,            # 6 / 12 / 24 个订阅月，或 None 表示终身
    prices=(                     # 价格生效记录，从起始日开始，按生效日升序
        PriceRecord(date(2024, 1, 31), 1000),   # 月度经常性收入，非负整数美分
        PriceRecord(date(2024, 3, 31), 2500),
    ),
    cancel_date=None,            # 可选取消日；当天零时终止资格
)
cal = CommissionCalendar([sub, ...])   # 接收完整快照，一次性校验并建索引
```

快照在构造时校验：交易编号唯一且为 ASCII、价格记录从成交日开始且无重复生效日、
金额为非负整数美分、窗口为 6/12/24 或终身。输入列表的排列顺序不影响结果。

## 查询

```python
# 两个自然月月初界定 [起始月, 结束月)，返回 txn_id -> 逐月佣金（整数美分）
result = cal.query(date(2024, 1, 1), date(2025, 1, 1))
result["TXN0001"]  # [c0, c1, ..., c11]，每月一个整数美分金额
```

## 计算规则

- **阶梯费率**：同一伙伴按成交日升序、同日按交易编号 ASCII 字典序排列，
  前 10 笔 10%，第 11 笔起 15%；取消的订阅仍占原序位，费率终身不变。
- **订阅月**：以原始起始日号为锚逐月推进；目标月没有该日号时取当月最后一天，
  之后仍用原始日号（如 1 月 31 日 → 2 月 28/29 日 → 3 月 31 日）。
  每个订阅月含起始日、不含下一边界日。
- **资格终止**：有限窗口在第 N 个锚定边界日结束；取消日在当天零时终止；
  两者取较早者，终止日当天不计佣。
- **每日应计**：当天 MRR × 费率 ÷ 当天所属完整订阅月的日数。
  变价、取消、窗口到期都不改变分母；无资格的日期为 0。
- **舍入**：先从服务起始日精确累计到某月末，再四舍五入到整数美分
  （半美分向上）；本月入账 = 本月末与上月末两个已舍入累计值之差。
  不逐日、不逐价格片段舍入；中途开始的查询仍从原始起始日累计。
  因此把连续月份拆成多次查询再合并，与一次整段查询的逐月金额完全一致。

## 精确性

所有金额以整数缩放单位（1 美分 = 100 × lcm(28,29,30,31) 个单位）累计，
订阅月天数只可能是 28–31 天，因此每日应计都是精确整数，
全程无浮点误差，结果精确到美分。

## 运行测试

```bash
python3 -m pytest tests/ -q
```

测试覆盖：月末起始跨闰年的边界推进、变价恰逢月锚或资格终止日的组合、
小样本与独立逐日精确参考实现（`tests/reference.py`，基于 `Fraction`）对照、
同日成交跨越第 10/11 笔且前序取消的阶梯归属、微小金额长期积累与
中途/拆分查询的逐月一致性，以及可复现的规模性能测试
（固定随机种子：1 万笔订阅、每笔最多 20 次变价、30 年历史，
查询末尾 12 个自然月，从接收快照到返回结果 < 10 秒）。
